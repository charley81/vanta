# VANTA production art-direction prototype

> Throwaway prototype for the decision in **Refine VANTA's production art direction**. Do not promote this code directly to production.

## Run

```bash
pnpm prototype:art-direction
```

Open <http://localhost:3000/prototype/art-direction?variant=A&route=home>.

- Bottom arrows or keyboard `←` / `→`: change art direction.
- Header: compare the same direction on Home, Product, and Synth.
- Query parameters `variant=A|B|C` and `route=home|product|synth` make any view shareable.
- MORPH sliders on Synth are interactive.

## Directions

- **A / Signal Black** — MONOLITH as precision signal equipment. Extends the current cinematic darkness with an OLED-derived signal color, technical rails, and a disciplined control-deck language.
- **B / Warm Field** — MONOLITH as a tactile editorial object. Uses warm paper, serif display type, photographic breathing room, and restrained circular controls.
- **C / Cut Plane** — MONOLITH as a force that reshapes space. Uses hard cropped planes, extreme typography, and the SUB-to-FRACTURE continuum as the compositional system.

All three preserve the approved VANTA palette, canonical MONOLITH language, and distinct route responsibilities. Images are local exports from the approved Figma work so the branch is self-contained.
